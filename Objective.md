# Project Objective

Build a production-style machine learning system that decides whether an incoming customer support ticket is high-risk (likely to escalate or breach SLA), explains the risk using similar past cases and policy documents, and monitors itself for data drift and performance decay.

## This Project Is Not
- A chatbot
- A UI-first demo
- A research experiment
- A toy data science project

## Definition of Success
- Accurate high-risk vs low-risk classification
- Actionable explanations using retrieved historical cases and policy context
- Continuous monitoring for data drift and model performance degradation
